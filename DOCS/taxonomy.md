# Taxonomia de elementos (v1)

## Categorias obrigatorias
- Clickable: links, botoes, elementos com role/button, elementos com handlers.
- Text input: input, textarea, contenteditable.
- Forms: form e seus campos relevantes.
- Images/media: img, video, audio, svg com role de imagem.
- Articles/sections/headings: article, section, header, h1-h6.
- Plain text blocks: p, div, span com texto relevante.

## Regras iniciais (rascunho)
- Priorizar elementos visiveis e interativos.
- Deduplicar elementos aninhados quando redundantes.
- Classificar por heuristicas simples primeiro; evoluir depois.
